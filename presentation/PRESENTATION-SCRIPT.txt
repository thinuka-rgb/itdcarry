SLIDE 1 — Same DNA. Different answer?
Hello, I’m Thinuka. My project is called ITDcarry. It asks: if we change a program’s settings, can it still find a DNA pattern we know is there? I tested this using made-up DNA data.

SLIDE 2 — One threshold. A different result.
Look at the two numbers: two and five. Our data has four separate pieces of evidence for the DNA pattern. The first setting needs only two, so it finds the pattern. The second needs five, so it doesn’t report it. Same data, different setting, different answer.

SLIDE 3 — Challenge it. Then compare exactly.
There are three steps. First, save the DNA pattern we want to find. Second, test both settings using the same made-up data. Third, check that the result matches exactly: where the pattern starts, how long it is, and its DNA letters. The details at the bottom describe our test pattern.

STEP 1 — One known marker
These are results from a real test on my computer. We start with the same made-up DNA data and a known pattern.

STEP 2 — Compatible profile
The first setting finds the pattern. All three details match, with four pieces of evidence.

STEP 3 — Changed profile

SLIDE 5 — A check on software. A traceable explanation.
This shows how one software setting can change a result. We can inspect the output and repeat the test. It tells us about the software, not a person’s health. It cannot diagnose anyone or check laboratory work. This demo ran on my computer; the cloud services listed below weren’t tested here.

SLIDE 6 — Help me test the question more deeply.
I’d like approval to show this project at school, with teacher guidance. I want classmates’ feedback, more test cases, and a clear record of its limits. My main question is: before comparing two answers, have we checked what the software can still find? Thank you.
